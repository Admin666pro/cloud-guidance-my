关于此项目

Product Nav — 一款拥有 iOS 26 水晶玻璃质感的产品导航网站，采用 Apple 设计语言。

技术栈：纯静态 HTML + CSS + JavaScript，后端使用 Cloudflare Pages Functions。

数据存储：产品数据通过 Cloudflare KV 存储（需绑定），本地开发时自动降级到 localStorage。

管理员密码：通过 Cloudflare 环境变量 ADMIN_PASSWORD 配置。

版本 1.0.0
